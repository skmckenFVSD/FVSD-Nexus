# FVSD Insights

FVSD Insights is a modern executive analytics portal for school principals and leadership staff. It helps leaders rapidly review attendance, literacy, student success, interventions, and school profile indicators during planning and performance meetings.

The Phase 1 experience is a single unified analytics workspace with Microsoft Fluent-inspired styling, a persistent left navigation menu, dashboard KPIs, charts, data tables, drill-down patterns, cross-filtering, and a prominent Analytics Assistant concept. Each page answers a distinct leadership question: attention, school comparison, learner support, attendance risk, literacy intervention, intervention results, and assistant-guided decision support.

A development-only role switcher is available to the authorized prototype user for Executive, School Administration, Teacher, Class Room Support, and Data Analyst (Administrator) views. Changing the prototype role adjusts page titles, descriptions, dashboard language, KPI labels, assistant prompts, recommendations, visible filter labels, navigation labels, and page availability while future production role behavior remains deferred to authenticated security and row-level filtering.

The application prioritizes insight discovery and decision support over data entry. Administrator-only Data Quality and Analytics Operations Centre pages support prototype validation of Microsoft Fabric readiness, semantic model health, dataset refresh status, assessment coverage, data product readiness, user adoption, security and RLS validation, role visibility, filter coverage, and governance workflows. The first Fabric integration target is a provider-routed Report Opens Over Time combination chart for the Usage Metrics semantic model, currently backed by mock data and ready for secure server-side Power BI binding. A secure analytics service abstraction defines Mock, Power BI REST Execute Queries, and Power BI MCP provider boundaries; mock data remains active until a server-side live integration is configured, with no credentials, secrets, access tokens, or direct MCP calls in browser-side React code. It uses realistic sample data only and intentionally defers live Dataverse/Fabric connectivity, authentication, production AI, RBAC enforcement, reporting exports, ALM, and operational telemetry to future phases.

Design direction: professional FVSD-branded public-sector education, compact executive density, accessible contrast, and a Power BI / Tableau / Microsoft Fabric dashboard feel.
