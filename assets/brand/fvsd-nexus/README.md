# FVSD Nexus logo pack

This directory contains the approved FVSD Nexus application mark supplied for the proof of concept.

## Files

- `FVSDNexus-32.png` through `FVSDNexus-1024.png` provide purpose-sized raster variants.
- `FVSDNexus-Master.png` is the highest-resolution raster source supplied with the pack.
- `FVSDNexus.svg` is retained as an original source asset, but it embeds a raster PNG rather than vector paths.

## Current application use

- The React application sidebar uses the 256 px PNG.
- Browser favicons use the 32 px and 48 px PNGs.
- The Apple touch icon uses the 256 px PNG.
- The repository project overview uses the 48 px PNG.

Use the smallest source that remains sharp at the intended display size. Do not treat the supplied SVG as an infinitely scalable vector master.
