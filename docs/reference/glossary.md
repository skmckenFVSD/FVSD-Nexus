# Glossary

| Term | Meaning in FVSD Nexus |
|---|---|
| Assessment Group | A governed grouping such as TOSREC, TOWRE, or CTOPP used to select analytical or operational content. |
| Canvas App | The existing Power Apps assessment-entry application using stable Dataverse structures. |
| Cohort Group | The `Term` table label used to group descriptive terms into Foundation and Curriculum. |
| CTOPP | An assessment used in applicable contexts, including Kindergarten. Exact operational scoring specification remains to be documented. |
| Dataverse | The authoritative operational data platform for assessment, IPP, reference, and related records. |
| Descriptive Term | A score classification such as Very Poor, Poor, Average, or Good, governed by reference data. |
| Fabric RLS | Row-level security enforced when the signed-in user's identity queries the Fabric semantic model. |
| Foundation | Cohort group replacing the previous Below Average group label. |
| Full PoC | The proposed end-to-end testable operational and analytical system targeted for February 2027, not automatic production authorization. |
| IPP | Individual Program Plan. |
| Nexus experience role | A role used to adapt navigation and UX. It cannot grant destination-service permission. |
| OneLake link | The established Dataverse-to-Fabric integration used to make operational data available analytically. |
| Period | Fall, Winter, or Spring. Summer is not an active assessment period. |
| Power Apps Premium | Per-user Power Apps licence proposed as a fallback if pay-as-you-go metering is unsuitable. |
| PR | Percentile Rank. |
| RLS | Row-level security. |
| SS | Standard Score. |
| TOSREC | Test of Silent Reading Efficiency and Comprehension. Scoring uses correct minus incorrect followed by a grade, period, and raw-score reference lookup. |
| TOSWRF | Test of Silent Word Reading Fluency. Scoring uses chronological age, period, and raw score. |
| TOWRE | Test of Word Reading Efficiency. Scoring includes SWE/RW, PDE/NW, and a composite lookup chain. |
| Truth store | The authoritative system in which operational records are created and maintained; Dataverse for Nexus. |
| WRAT-5 | Wide Range Achievement Test, Fifth Edition. The documented scoring pattern currently covers Math Computation. |

Add terms when they become important to understanding product behaviour. Do not use the glossary to define rules that belong in a capability or architecture document.
